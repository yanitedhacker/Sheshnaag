# V5 Wave 0 — W0a (RBAC) Implementation Plan

> **For agentic workers:** TDD task-by-task. Steps use checkbox (`- [ ]`) syntax.

**Goal:** Ship the 5-role permission system that every other V5 sub-track depends on.

**Architecture:** Three new tables (`roles`, `permissions`, `role_permissions`) reuse the existing `tenant_memberships.role` column as the user→role binding (no separate `user_roles` table — that was the orchestration plan's intent but the existing model already covers it). RBAC service maps role→permissions. New FastAPI deps `require_role()` and `require_permission()` mirror the style of existing `require_scope()` and `require_capability()`.

**Tech Stack:** SQLAlchemy 2.x + Alembic + FastAPI + pytest. No new runtime deps.

**Key deviation from orchestration plan:** drop the proposed `user_roles` table; extend `tenant_memberships.role` validation instead. Rationale: `tenant_memberships` already binds `(tenant_id, user_id) → role`. Adding `user_roles` duplicates that with a new pk and forces every reader of "what role does this user have" to consult two tables. The five V5 roles become the new vocabulary for that column.

```python
"""V5 RBAC models — roles, permissions, role-permission links."""
from sqlalchemy import Column, DateTime, ForeignKey, String, Text
from sqlalchemy.orm import relationship

from app.core.database import Base
from app.core.time import utc_now


class Role(Base):
    __tablename__ = "roles"

    name = Column(String(50), primary_key=True)
    description = Column(Text, nullable=False)
    created_at = Column(DateTime, default=utc_now)


class Permission(Base):
    __tablename__ = "permissions"

    name = Column(String(80), primary_key=True)
    description = Column(Text, nullable=False)
    created_at = Column(DateTime, default=utc_now)


class RolePermission(Base):
    __tablename__ = "role_permissions"

    role_name = Column(String(50), ForeignKey("roles.name", ondelete="CASCADE"), primary_key=True)
    permission_name = Column(String(80), ForeignKey("permissions.name", ondelete="CASCADE"), primary_key=True)
    created_at = Column(DateTime, default=utc_now)
```

```python
"""V5 RBAC service — role / permission checks for FastAPI deps."""
from __future__ import annotations
from typing import List, Set

from sqlalchemy.orm import Session

from app.models.rbac import Permission, Role, RolePermission


class RbacService:
    """Stateless RBAC reader. Caches role→permission set per session."""

    def __init__(self, session: Session) -> None:
        self._session = session
        self._cache: dict[str, Set[str]] = {}

    def has_permission(self, role_name: str, permission_name: str) -> bool:
        return permission_name in self._permissions_for(role_name)

    def permissions_for_role(self, role_name: str) -> List[str]:
        return sorted(self._permissions_for(role_name))

    def list_roles(self) -> List[str]:
        return [r.name for r in self._session.query(Role).order_by(Role.name).all()]

    def list_permissions(self) -> List[str]:
        return [p.name for p in self._session.query(Permission).order_by(Permission.name).all()]

    def validate_role_name(self, role_name: str) -> bool:
        return self._session.query(Role).filter_by(name=role_name).first() is not None

    def _permissions_for(self, role_name: str) -> Set[str]:
        if role_name in self._cache:
            return self._cache[role_name]
        rows = (
            self._session.query(RolePermission.permission_name)
            .filter_by(role_name=role_name)
            .all()
        )
        out = {row[0] for row in rows}
        self._cache[role_name] = out
        return out
```
